# 🏰 Лабиринт Сокровищ

Текстовая приключенческая игра в жанре квеста, где игрок исследует лабиринт, собирает предметы, решает головоломки и ищет сокровище

## 🎮 Особенности

- **Текстовый интерфейс** на русском языке
- **Система инвентаря** для сбора и использования предметов
- **Головоломки** в каждой комнате
- **Случайные события** во время перемещений
- **Система очков** за решение загадок
- **Цветовое оформление** консоли

## 🎯 Цель игры

Найти ключ от сокровищницы и открыть сундук

## ⌨️ Команды управления

| Команда                       |Описание
|-------------------------------|------------------------------------------------
| `go <direction>`              | Перейти в направлении (north/south/east/west) 
| `north`/`south`/`east`/`west` | Краткая форма перемещения 
| `look`/`ls`                   | Осмотреть текущую комнату 
| `take <item>`/`tk`            | Поднять предмет 
| `use <item>`/`f`              | Использовать предмет из инвентаря 
| `inventory`/`i`               | Показать инвентарь 
| `solve <answer>`              | Решить загадку в комнате 
| `quit`/`q`                    | Выйти из игры 
| `help`                        | Показать справку по командам

## 🎁 Предметы

Подбирай предметы, чтобы пройти игру

## 🧩 Головоломки

В комнатах есть уникальные загадки

## ⚠️ Случайные события

При перемещении между комнатами могут происходить cлучайные события
